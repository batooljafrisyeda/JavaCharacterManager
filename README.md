# Java Character Manager

A Java Swing desktop application developed for my Object-Oriented Programming course. 
The project simulates a fantasy adventurer guild where users can create adventurers, assign races and jobs, manage character statistics, and progress through levels.

## Features
Adventurer Management: Add, search, display, and remove adventurers from the guild.

Race and Job System: Assign races and choose jobs such as Warrior, Mage, Tank, Archmage, and Berserker.

Character Statistics: Calculate character stats based on race attributes, racial bonuses, and job stats.

Level Progression: Level up adventurers through their assigned jobs, with a maximum guild level of 100.

Guild Management: Enforce a maximum guild size of 50 adventurers and prevent duplicate names.

Guild Statistics: Calculate the average level of adventurers who have an assigned job.

Graphical Interface: Interact with the system through a Java Swing GUI.

## How to Run
Requirements
- Java Development Kit
- Eclipse IDE
Setup
- Download the project.
- Open Eclipse and import the project: File → Import. General → Existing Projects into Workspace. Browse. Select the project. Finish.
- Run the application: Package Explorer. src. systemMainClasses. AdventurerMain.java.
  (Click the green Run button or right-click the file and select Run As → Java Application)
